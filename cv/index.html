Research interests

Gravitational-wave astrophysics, with a focus on black holes. Bringing together all aspects of gravitational-wave science (detection, source modeling, inference, and astrophysics and physics theory) with inference and machine-learning techniques to carry out precision measurements with present and future detectors on the ground (LIGO, Cosmic Explorer) and in space (LISA).

Software

  • ringdown
    Python package for analyzing black-hole ringdowns in gravitational-wave data using Hamiltonian Monte Carlo (PyPI).
  • jim
    Accelerated and robust parameter estimation for gravitational waves using a JAX-based sampler (PyPI).
  • GWaxion
    Python package for computations related to gravitational-wave emission by ultralight bosons, a dark-matter candidate (PyPI).
  • pulsarutils
    Python-based Bayesian inference pipeline for testing general relativity with continuous gravitational waves.
  • Other contributions
    LIGO–Virgo data-analysis code in Python and C++, including LALSuite and GWpy. See also the software page.
